# MajorDoMo Solar Planner (RU)

Планировщик солнечной генерации и ночного заряда батарей для
[MajorDoMo](https://github.com/sergejey/majordomo). Модуль получает прогнозы PV
из нескольких источников, прогнозирует потребление дома, интервально моделирует
энергобаланс и рассчитывает **TargetSocAt07** — целевой SOC батарей к концу
льготного тарифа — после чего формирует выполнимое расписание Deye Time of Use.

> **Безопасно по умолчанию.** Модуль по умолчанию **не пишет в инвертор**. Он
> работает в режиме `shadow`: только рассчитывает и сохраняет план. Реальное
> управление требует отдельного разрешения, проверенного device profile и режима
> `armed`.

## Возможности

- Мультипровайдерный прогноз PV: **Open-Meteo** (погода + локальная PV-модель),
  **Forecast.Solar**, **Solcast** (домашний доступ) — независимые адаптеры с
  учётом квот, backoff и circuit breaker.
- Прогноз нагрузки (прозрачный статистический метод + ручной fallback).
- Интервальный энергетический симулятор с проверкой физических инвариантов.
- Расчёт `TargetSocAt07` перебором кандидатов со сценариями
  `base / low_pv / high_load / high_pv` и явным статусом невыполнимости.
- Компилятор TOU (максимум 6 периодов для серии Deye SG05LP3, без пропусков и
  наложений, корректный переход через полночь) с повторной симуляцией.
- Объяснение каждого решения, воспроизводимое из архивированных входов.
- Режимы безопасности: observe / shadow / approval_required / armed / … с
  readback и audit log.
- UI MajorDoMo. Без обязательной зависимости от Home Assistant. PHP 7.3–8.x.

## Сезонная универсальность

Никаких жёстких правил «зима — 100%, лето — 30%». Сезонное поведение вытекает из
почасового энергобаланса, фактической ёмкости, нагрузки, резерва и прогноза PV.

## Быстрый старт

```bash
sudo tar -xzf solarplanner.tgz -C /var/www/html/
php /var/www/html/scripts/cycle_solarplanner.php   # под supervisor/systemd
```

Откройте модуль в MajorDoMo, заполните настройки (координаты и ключи — приватные
и маскируются), работайте в `shadow` до подтверждения всех параметров. Подробнее
— `docs/installation.md` и `docs/configuration.md`.

## Тесты

```bash
php tests/run.php
```
